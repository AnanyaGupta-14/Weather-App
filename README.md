# ☀️ Sunny Weather

A simple and responsive weather application built using HTML, CSS, and JavaScript. It uses the OpenWeather API to fetch real-time weather information for any city.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Displays current temperature
- 💧 Shows humidity
- 💨 Shows wind speed
- ☁️ Displays weather condition with icons
- 📱 Responsive design
- ❌ Error handling for invalid cities

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeather API

## 📌 What I Learned

- Working with APIs
- Using `fetch()` and `async/await`
- Handling JSON data
- DOM manipulation
- Creating a responsive UI with CSS

## 🚀 How to Run

1. Clone the repository.
2. Add your OpenWeather API key in `script.js`.
3. Open `index.html` in your browser.
4. Enter a city name and search for its weather.
